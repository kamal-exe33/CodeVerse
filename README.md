# CodeVerse 🚀

### Student Developer Club

> **Build. Learn. Code. Grow.**

CodeVerse is a clean and responsive developer club website created for students interested in programming, web development, collaboration and project building.

---

## ✨ Features

- Responsive design for desktop, tablet and mobile
- Clean and modern user interface
- Sticky navigation with smooth scrolling
- About and activities sections
- Contact links for Email, GitHub and LinkedIn
- Light Mode / Dark Mode toggle
- CSS Flexbox and Grid layouts

## 🛠️ Built With

**HTML5** • **CSS3** • **JavaScript**
